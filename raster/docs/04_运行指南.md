## 三、配置参数

### 3.1 质量过滤参数 (settings.py)

配置唯一来源为 `src/config/settings.py`，`QualityConfig` 无独立默认值：

```python
QUALITY_CONFIG = {
    # 必须过滤
    'wse_qual_max': 1,              # good(0) 或 suspect(1)
    'water_area_qual_max': 1,
    'cross_track_min': 10000,       # 排除近 nadir 伪影（米）

    # 推荐过滤
    'water_frac_min': 0.3,          # 水体比例阈值
    'min_valid_pixels': 100,        # 最小有效像元数
    'wse_uncert_max': 10.0,         # 最大不确定度（米）

    # 可选过滤（D版本跳过）
    'skip_ice_filter': True,        # D版本 ice_clim_flag 全为255，需跳过
}
```

### 3.2 WSE 聚合参数

所有聚合层统一使用不确定度加权平均（统计最优）：

- **Merge 阶段**（多 granule 重叠区 → 单个像素）：`wse = Σ(wse_i/σ²_i) / Σ(1/σ²_i)`
- **湖泊聚合阶段**（多像素 → 单个湖泊值）：同样使用 `1/σ²` 加权平均
- **wse 字段本身**就是加权平均值，`wse_med`（中位数）作为备用
- **wse_std** 基于与加权平均相同的像元子集计算

## 四、运行命令

### 4.1 完整处理（一次性运行）

```bash
cd /data/lyf/geo/Lake

# 激活 conda 环境
conda activate py10

# 完整运行（阶段一 + 阶段二）
python -m src.process.main --prior data/prior/QB58_716_4.shp

# 测试模式（仅处理3个时间组）
python -m src.process.main --prior data/prior/QB58_716_4.shp --test

# 限制处理数量
python -m src.process.main --prior data/prior/QB58_716_4.shp --max-files 10
```

### 4.2 分布式计算（分阶段运行）

**阶段一：QC + 空间拼接 → 输出中间影像**

```bash
# 仅执行阶段一，输出中间影像到 output/merged/
python -m src.process.main --prior data/prior/QB58_716_4.shp --stage merge
```

**阶段二：读取中间影像 → 湖泊裁切 + WSE 计算**

```bash
# 仅执行阶段二，从 output/merged/ 读取中间影像
python -m src.process.main --prior data/prior/QB58_716_4.shp --stage clip
```

### 4.3 命令行参数说明

| 参数 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--prior` | `-p` | 必填 | 先验湖泊边界 Shapefile 路径 |
| `--raster` | `-r` | 配置路径 | Raster 数据目录 |
| `--output` | `-o` | 配置路径 | 输出目录 |
| `--stage` | `-s` | `all` | 处理阶段：`all`=全部, `merge`=仅拼接, `clip`=仅裁切 |
| `--max-files` | `-m` | 无 | 最大处理文件数（测试用） |
| `--test` | `-t` | False | 测试模式（处理3个时间组） |

### 4.4 输出目录结构

```
output/
├── merged/                      # 阶段一输出（中间影像）
│   ├── 037_467_PID0.tif        # 拼接后的 WSE 影像
│   ├── 037_467_PID0.json       # 元数据（group_id, date）
│   └── ...
├── <lake_id>/                   # 阶段二输出（每个湖泊）
│   ├── rasters/
│   │   └── <date>_wse.tif
│   └── vectors/
│       └── <date>_contour.shp
└── summary/
    ├── lake_timeseries.csv      # 时序汇总
    └── statistics.json          # 统计信息
```

## 五、输出说明

### 5.1 时序数据文件
- 路径：`output/summary/lake_timeseries.csv`
- 格式：CSV，逗号分隔
- 编码：UTF-8
- 主要字段：
  - `wse`：不确定度加权平均水位（主要值）
  - `wse_med`：水位中位数（备用）
  - `wse_uncert`：合并不确定度

### 5.2 统计信息文件
- 路径：`output/summary/statistics.json`
- 格式：JSON
- 内容：处理统计、质量报告

## 六、常见问题

### Q1: 内存不足
- 减少并行进程数
- 分批处理湖泊
- 使用 dask 分块读取

### Q2: 找不到有效数据
- 检查先验数据坐标系
- 检查 Raster 文件覆盖范围
- 放宽过滤条件

### Q3: 坐标系不匹配
- 确保先验数据为 WGS84
- Raster 会自动转换
- 检查 UTM Zone
