## 一、产品概述

### 1.1 产品信息
- **产品名称**: SWOT Level 2 KaRIn High Rate Raster Product (L2_HR_Raster)
- **文件格式**: NetCDF-4
- **分辨率**: 100m 和 250m (标准产品)
- **Granule 大小**: 128 km × 128 km (非重叠)
- **版本**: C (PIC2) 和 D (PID0)

### 1.2 文件命名规则
```
SWOT_L2_HR_Raster_<resolution>_<grid>_<overlap>_x_x_x_<cycle>_<pass>_<scene>F_<start>_<end>_<crid>.nc
```

**示例**:
```
SWOT_L2_HR_Raster_100m_UTM01C_N_x_x_x_034_287_002F_20250618T233535_20250618T233556_PID0_01.nc
```

**字段说明**:
| 字段 | 示例 | 说明 |
|------|------|------|
| resolution | 100m | 空间分辨率 |
| grid | UTM01C | UTM Grid (Zone + C/W) |
| overlap | N | 重叠标识 |
| cycle | 034 | 轨道周期号 |
| pass | 287 | 轨道号 |
| scene | 002F | 场景标识 |
| start | 20250618T233535 | 开始时间 |
| end | 20250618T233556 | 结束时间 |
| crid | PID0 | 产品版本标识 |

| 值 | 含义 | 建议 |

## 六、质量控制配置

### 6.1 推荐过滤条件（SWOT官方标准）

```python
QUALITY_CONFIG = {
    # 必须过滤
    'wse_qual_max': 1,              # good(0) 或 suspect(1)
    'water_area_qual_max': 1,
    'cross_track_min': 10000,       # 排除近 nadir 伪影

    # 可配置过滤
    'water_frac_min': 0.0,          # 水体比例阈值（0表示不过滤）
    'min_valid_pixels': 100,        # 最小有效像元数
    'wse_uncert_max': 10.0,         # 最大不确定度 (m)

    # 可选过滤（D版本可能跳过）
    'skip_ice_filter': True,
}
```

### 6.2 典型过滤效果

基于测试数据（D版本）:
- 初始有效像元: 1,556,078
- WSE质量过滤后: 1,080,879 (保留 69%)
- cross_track过滤后: 1,380,077
- 最终有效像元: 957,609 (保留率 61.5%)

## 七、输出数据格式

### 7.1 TIF栅格输出

**双通道格式**:
- 通道1 (band=1): WSE (m)
- 通道2 (band=2): water_frac (0-1)
- NoData值: -9999.0
- 投影: 与原始数据一致 (UTM)

| wse_med | float | 水位中位数（备用，m） |
